# Instructor Guide

## Before the workshop

- Send setup 48 hours early and collect ready/repairable/replay-only status.
- Rehearse with the pinned ADBT package, Vega SDK 0.22, and target VDA image.
- Verify Pocket Cinema, all mini-harness recordings, the complete checkpoint, and Bee fixture.
- Keep the complete implementation hidden until the TV exercise ends.

## Four-hour run sheet

## Condensed three-hour version

Use Pocket Cinema for everyone, demonstrate rather than build Step 1, omit live Bee retrieval, and keep Vega performance analysis out of scope.

## Failure cards

- **Install:** try once for ten minutes, then replay.
- **Model:** preserve logs and move to the phase checkpoint.
- **Budget:** stop; never raise the cap without the participant.
- **Kepler:** separate environment failure from product failure; use complete checkpoint.
- **VDA:** use screenshots and transition report.
- **ADBT:** use pinned tool evidence and continue with production fixture.
- **Bee:** use the synthetic file snapshot.
- **Stale process:** inspect status/logs, terminate only the workshop child, then checkpoint.

## Success measures

Track core-harness completion, verified TV adaptation, live Vega completion, Bee completion, checkpoint use, cost, and help requests separately. The core learning outcome must not depend on device or Bee success.
