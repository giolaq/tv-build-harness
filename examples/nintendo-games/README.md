# Arcade Showcase Example

The committed `content.json` is synthetic. It is safe for demos, screenshots, fixtures, and redistribution.

`fetch-content.js` is provided only as a local experiment for instructors who want to see how a real catalog source might be transformed. It fetches third-party game metadata and writes `content.fetched.json`, which is ignored by Git.

Do not commit fetched output, owner-hosted images, real game descriptions, or third-party catalog exports.
