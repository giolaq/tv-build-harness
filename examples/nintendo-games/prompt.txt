A premium game discovery app for a synthetic console catalog. The visual identity should feel like a modern storefront: bold, playful, refined, and energetic without referencing any real platform owner or game franchise. Use deep navy and charcoal backgrounds with coral accents and bright teal interactive elements.

Home screen: full-bleed hero showcasing a featured game with its poster art, a cinematic scrim gradient, and a prominent "View Game" CTA. Category rails below organized by genre (Action, Adventure, RPG, etc.) with large 16:9 cards showing game art. Each card should feel collectible — like a game box on a shelf.

Detail screen: immersive game page with the poster image filling the top third, metadata pills (publisher, players, age rating), and a bold description area. Focus state should feel like picking up a game case — slight lift with a clean colored border.

Visual signatures: the coral accent should appear sparingly but memorably (focus borders, CTAs, section accents). Cards should have subtle depth with layered surfaces. The overall tone is confident and curated — like a personal game library, not a cluttered store.
