# Changelog Site: Brand

Apply the brand kit to the static changelog site.

Requirements:

- Use the brand name `{{brand.name}}` in the page title, header, and footer.
- Use `{{brand.primary_color}}` for primary navigation or headings.
- Use `{{brand.accent_color}}` for links, highlights, or release badges.
- Use `{{brand.background_color}}` as the page background or main surface background.
- Use `{{brand.font_family}}` as the preferred font family with a system fallback.

Keep the design restrained and documentation-focused.
