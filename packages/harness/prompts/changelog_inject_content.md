# Changelog Site: Inject Content

Treat `content.videos` as release-note records:

- `title` is the release heading.
- `description` is the release summary.
- `tags` are change categories.
- `id` is the stable slug.

Update the static site so every release from the content manifest appears on the releases page. The latest release, `2.3.0 - Search and Saved Views`, must be visible on the homepage and releases page.

Do not include video-player UI. This is a changelog/docs site.
