# Changelog Site: Clone Template

Create a minimal static site project in the current app directory.

Requirements:

- Do not create a React Native or TV app.
- Create `package.json` with a `build` script that succeeds locally.
- Create `src/` or plain root HTML/CSS/JS files, whichever is simplest.
- Include pages or routes for home, releases, and about.
- Keep dependencies minimal. Prefer zero runtime dependencies.
- The generated app must be understandable as a docs/changelog site.

Use the loaded changelog-static-site skill as the contract for output shape.
